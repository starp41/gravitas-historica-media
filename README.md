# Gravitas Historica: media

Pictures for the Steam Workshop pages of [Gravitas Historica](https://gravitashistorica.eu), a historical systems overhaul mod for Europa Universalis V by IronPrats. Steam embeds pictures only from hosts it accepts, so they are served from here.

They are made by `scripts/workshop/images.mjs` in the site's repository; copy the new versions into `workshop/` when they change.

An unofficial fan project, not affiliated with or endorsed by Paradox Interactive.
